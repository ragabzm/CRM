# Assist has no contracts, and should not grow any.

A contract exists so that a lower-tier module can be handed something a higher
one implements. Nothing depends on Assist: it reads Tickets and Knowledge,
calls the AI port, and is read by nobody.

If a contract appears here it means something below has started depending on an
AI suggestion — and a proposal being load-bearing for behaviour is exactly the
automation this epic refuses. AI proposes; a person decides.
