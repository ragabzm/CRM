# مشاكل الواجهة — جولة بصرية 2026-09-02

جولة على الستاك الشغال في Docker (`localhost:3000`)، **من غير تسجيل دخول**.
**ما اتصلحش أي كود** — الملف ده تسجيل بس.

نطاق الجولة: الصفحات المفتوحة + الصفحات اللي المفروض تكون محمية. الجزء اللي
بعد تسجيل الدخول لسه ما اتشافش (محتاج حد يسجّل الدخول — شوف `DEV-CREDENTIALS.md`).

---

## 🔴 عالي — صفحات محمية بتفتح من غير تسجيل دخول

**الأعراض:** كل الصفحات دي فتحت بالكامل والمتصفح **مش مسجّل دخول**. مفيش تحويل
لـ `/sign-in`، ومفيش `ForbiddenState`.

| المسار | اللي حصل |
|---|---|
| `/` | الصفحة الرئيسية اتعرضت كاملة بالشل |
| `/customers` | الجدول والفلاتر وزرار "Add customer" كلهم ظاهرين |
| `/profile` | الفورم كامل ظاهر (بحقول فاضية) |
| `/admin/audit-log` | **شاشة الأدمن** اتعرضت كاملة بالفلاتر والجدول |

`/admin/audit-log` هي الأخطر: ستوري 499 بندها العاشر بيقول
> `ForbiddenState` rendered when API returns `403`

اللي بيحصل فعلاً إن الصفحة بتترسم عادي وبتعرض حالة "مفيش نتايج".

**ملاحظة:** الـ API نفسه محمي صح — بيرجع `401` مع Problem Details:
```json
{"type":"https://errors.ragab-crm/platform.unauthorized","status":401,
 "code":"platform.unauthorized","detail":"This endpoint requires an authenticated caller."}
```
المشكلة في الواجهة: بتترسم قبل ما تتأكد من الجلسة، وبتعامل الـ 401 كأنه
"مفيش بيانات".

## 🔴 عالي — الشل بيترسم مرتين

**الصفحات المتأثرة:** `/customers`، `/admin/*`
**الصفحات السليمة:** `/`، `/profile`، `/sign-in`

**الدليل** — نص الصفحة من داخل `<main>` على `/customers`:
```
Home
Tickets
Customers
Ragab CRM        ← شريط علوي تاني جوه الأول
العربية
Customers
Add customer
```

يعني فيه شريط جانبي وشريط علوي (باسم التطبيق ومبدّل اللغة وجرس الإشعارات)
**جوه** الشريط الجانبي والعلوي الأصليين. بصرياً: قايمة تنقّل عند `x≈40`،
وقايمة تانية مطابقة عند `x≈260`.

`AppShell` متركّب مرتين على المسارات دي.

## 🟠 متوسط — حالة خطأ وحالة فاضية بيظهروا مع بعض

**المسار:** `/customers`

في نفس اللقطة:
- بانر أحمر: **"Customers could not be loaded."**
- وتحته على طول: **"No customers match this search"** مع أيقونة الحالة الفاضية

الاتنين بيتناقضوا: واحد بيقول التحميل فشل، والتاني بيقول التحميل نجح ومفيش نتايج.

ستوري 493 بندها التاسع بيقول `EmptyState` و `ForbiddenState` لازم يكونوا
**لا يلتبسوا** — هنا مفيش ولا واحد فيهم اتعرض للحالة الحقيقية (401)، واتعرضوا
الاتنين مع بعض بدل واحد صح.

## 🟠 متوسط — `/tickets` بيدي 404 غير منسّقة جوه الشل

**المسار:** `/tickets` (من الشريط الجانبي مباشرة)

صفحة 404 الافتراضية بتاعة Next.js — **بلوك أسود** بيغطي منطقة المحتوى كلها،
مكتوب فيها `404 | This page could not be found.`، وهي **جوه** الشل بتاع
التطبيق (الشريط الجانبي والعلوي فوقها).

مفيش `app/not-found.tsx` في المشروع، فالمستخدم بيشوف صفحة خطأ لا شكلها ولا
لغتها من التطبيق (إنجليزي ثابت، مش من `messages/`).

السبب الجذري: `Sidebar.tsx` سطر 23 بيحط وجهة `/tickets` بينما `app/tickets/`
مش موجود أصلاً. متوقَّع — stories التذاكر (503→507) لسه ما خلصتش — بس النتيجة
إن رابط في التنقّل الأساسي بيكسر.

## 🟡 منخفض — عنصر التنقّل بيختفي على صفحة الـ 404

**المسار:** `/tickets`

الشريط الجانبي بيعرض `Home` و `Customers` بس، وبينهم **فراغ فاضي** مكان
`Tickets`. يعني العنصر بيترسم بس مش ظاهر — غالباً لون النص بيبقى زي لون
الخلفية لما العنصر يكون هو الحالي.

على `/customers` العنصر الحالي بيبقى **أسود عريض** وباين عادي، فالسلوك مش متسق.

## 🟡 منخفض — `/profile` بحقول فاضية من غير أي إشارة

**المسار:** `/profile`

حقول Name و Email **فاضية تماماً**. مفيش مؤشر تحميل، مفيش رسالة خطأ، مفيش
حالة "مش مسجّل دخول". الفورم مطروح كأنه جاهز للاستخدام وهو مش هيشتغل.

## 🟡 منخفض — طلب API غير مصادَق ومش JSON بيرجّع 500

**إعادة الإنتاج:**
```bash
curl -i http://localhost:8000/api/v1/customers          # → 500
curl -i -H "Accept: application/json" \
        http://localhost:8000/api/v1/customers          # → 401 صح
```

**من لوج الكونتينر:**
```
{"message":"Route [login] not defined.",
 "context":{"exception":{"class":"Symfony\\Component\\Routing\\Exception\\RouteNotFoundException",
 "file":"/app/vendor/laravel/framework/src/Illuminate/Routing/UrlGenerator.php:542"}},
 "level_name":"ERROR","module":"Customers"}
```

لما الطلب مايطلبش JSON، Laravel بيحاول يحوّل لراوت اسمه `login` — وهو مش
مسجّل — فبيرمي استثناء وبيطلع 500 بدل 401.

ستوري 492 بندها التامن بيقول:
> Every non-2xx response is `application/problem+json`

الرد ده مش كده.

## اللي لسه ما اتشافش

الجولة كلها اتعملت **من غير تسجيل دخول**، فالجزء ده لسه محتاج مراجعة:

- سلوك تسجيل الدخول نفسه والتحويل بعده
- `/customers` وفيها بيانات فعلية — الجدول، الفرز، الفلاتر، البحث، الأعمدة
- `/customers/[id]` — البروفايل، مسار الملاحظات، مسار المرفقات (رفع، "قيد الفحص"، تحميل)
- `/admin/ticketing` — التصنيفات والردود السريعة (CRUD)
- `/admin/service-levels`، `/admin/email`، `/admin/platform`
- `/admin/audit-log` وفيه إدخالات فعلية
- `/profile` وفيه بيانات
- **الوضع العربي RTL على كل الصفحات دي**
